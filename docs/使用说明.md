# v2.1.0 使用说明

第一次使用请看[新手教程](新手教程.md)，各页面外观见[界面截图](界面截图.md)。

## 选择游戏与退出检查

游戏进入实际画面后点击“检测 GPU · 10 秒”，采样显示真实经过时间。准备计数器和识别路径可能另花时间。负载只用于排序，需核对程序名和完整路径。

检测失败时用“手动选择 EXE”，选真正运行游戏画面的程序。选好后直接继续当前页面，不需要重新检测。

正常退出游戏后点击“检查游戏已退出”，通过后才可安装。更换目标会撤销退出确认；准备文件后和备份后再次检查进程，不自动结束游戏。

## 完整包安装与更新

安装范围为 version.dll、dlssg_sm86.ini 与 dlssg_sm86/ 配套载荷。下载固定到同一提交，排除历史归档、其他代理和运行日志；检查后端、帧生成内核包与运行库是否齐全，接受小于 1 MiB 的有效 x64 代理。

先准备完整缓存，再建立逐文件备份。新增、覆盖和移除的旧载荷均有记录，dlssg_sm86/logs/ 不覆盖、不删除。部署失败按安装前记录回滚。

使用官方配套 INI，新版参数位于 [DLSSG]。不自动合并旧配置；自定义参数请先另存，更新后按新版说明核对。发现其他根目录代理名称时列出，不自动删除；确认其来源和兼容性后再继续。

## 完整包缓存

提交未变且缓存有效时复用。上游更新或本地缓存损坏时，在临时目录准备完成后再切换；更新失败且完整缓存有效时提示后使用，否则停止，游戏原文件不变。

v2.0.0 两文件缓存不作为完整包使用，首次升级需联网，失败不清空旧缓存。“检查完整包缓存更新”只准备公共文件，不自动更新任何游戏。

## 备份与恢复

同时读取文档目录集中备份及当前游戏附近的旧版 DLSS帧生成备份。找旧版记录前先选中对应 EXE，再刷新。

恢复前校验原备份、保存当前快照，再恢复所选操作之前的状态。更新前已有旧版时，恢复更新记录会回到旧版，不一定完全卸载。

安装前存在的文件恢复原内容；安装新增文件只有仍与记录一致才移除。日志及未列入该恢复点的文件保留。v2.0.0 与旧批处理记录仍只恢复两个原文件，不扩大范围。

## 状态与日志

“游戏设置”列出根文件、必需载荷和最近记录。更改日志等级先检查游戏退出，仅备份并修改 INI。等级 0 关闭、1 仅错误、2 配置与能力、3 详细跟踪，游戏重启后生效。

上游 0.4.x 默认日志位于 dlssg_sm86/logs/dlssg_sm86.log。管理器“操作日志”仅记录本次窗口，可导出，不自动上传。

## GUI 更新与 DPI

默认启动时检查本仓库正式 Release；新版显示右下角红灯，点击确认后下载、校验、保留旧 EXE 并重启。可在缓存页关闭启动自动检查。v2.1.0 保持 v2.0.0 的更新协议。

字体、图标、按钮和表格随显示器 DPI 调整，跨屏重新布局，空间不足时滚动访问按钮，不要求将 Windows 缩放改为 100%。

## 已知限制

- RTX 40 为实验性支持，需要上游要求的 R580+ 驱动，不强制解锁倍率。
- 部署完成不等于游戏内功能生效，不为没有帧生成功能的游戏添加菜单。
- 仅用于允许修改的游戏，不绕过反作弊；其他同名代理可能冲突。
- 不合并自定义 INI、不提供超分设置。独立 Win10 设备和 RTX 40 实卡尚未测试。
- EXE 未签名，不应关闭安全软件或绕过组织策略。断电或强制终止可能需要按恢复说明处理。
