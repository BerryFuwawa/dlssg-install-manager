- GUI 新版比较、红灯关联版本数据、错误哈希与外站地址被拒绝。

## GPU 时间实测

先发现逐个 `PerformanceCounter.NextValue` 与逐样本路径查询造成开销：十个样本需要约 15–16 秒。已改为原生 PDH 批量采集，路径解析后移，不在采样窗口内查询 WMI。

三轮各十个样本，窗口时长：

| 轮次 | 第 10 个样本实际时间 |
| --- | --- |
| 1 | 10.012 秒 |
| 2 | 10.016 秒 |
| 3 | 10.006 秒 |

30 个样本相邻间隔约 `0.987–1.018` 秒，全部通过 `0.90–1.20` 秒的实测容差。该容差是测试验收条件，不是 Windows 硬实时承诺。

## 界面检查与局限

已生成启动界面截图并检查中文裁切、卡片、按钮与布局；修正高 DPI 下字体尺寸和控件边界不匹配的问题。测试中模拟新版本显示，检查右下角红灯；公开 README 截图为未选择游戏的真实初始状态。

没有对所有 DPI/显示器、GPU 驱动、反作弊或游戏组合做实测。自动检测只能给出 GPU 高负载候选，不能证明进程是游戏或判断游戏允许加载 DLL。自动更新测试使用隔离夹具，不宣称验证所有权限/跨盘/突然断电情形。EXE 没有 Authenticode 签名。
