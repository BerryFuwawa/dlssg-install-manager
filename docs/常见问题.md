# 常见问题

下载、解压、首次安装请先看[新手教程](新手教程.md)。下面按问题查找。

## GitHub 附件应该下载哪一个？

第一次用选名字以 `portable.zip` 结尾的便携包，解压后打开里面的 `DLSSG-Install-Manager.exe`。只想要程序也可以下载单独的 EXE。不要选 `Source code`；它是源码。`update-manifest.json` 是自动更新校验文件，不用手动处理。

## 安装完成了，为什么游戏没有帧生成选项？

工具只负责部署与校验文件，不能为不支持 DLSS 帧生成的游戏添加功能。也可能是主程序选错、游戏不加载 `version.dll`、图形接口或驱动不符合上游要求。先正常退出游戏，保留日志，必要时通过“备份与恢复”撤销；不要随便改 DLL 名称或重复覆盖其他模组。对游戏内设置的判断以游戏和上游说明为准。

## 更新会保留我改过的 INI 参数吗？

不会自动合并。本版安装/更新会先备份原文件，再写入官方配套 DLL 和默认 INI。自定义参数请先额外保存，更新后按新版本文档核对；不要直接拿旧配置覆盖新配置。需要回退时选择对应的安装前备份。

## 提示没有权限、文件被占用怎么办？

先确认游戏真正退出，关闭占用目标文件的编辑器等程序，再重试。管理器自身请放在个人可写文件夹。如果目标目录由系统或组织保护，停止操作，不要改系统目录权限或关闭安全软件。只有确定信任程序、目标游戏允许修改且确实需要提升权限时，才考虑右键“以管理员身份运行”；管理员权限不能解决反作弊拦截或游戏不兼容。

## 屏幕缩放较高，找不到下面的按钮怎么办？

工具会按 Windows DPI 放大文字和控件。不必把系统缩放改成 100%；尝试最大化窗口，空间不足时滚动内容区，查看下方和右侧按钮。不建议给 EXE 强制设置“高 DPI 缩放替代”，这可能影响内置缩放逻辑。若仍裁切，反馈分辨率、缩放比例和截图。

## 怎么提供报错信息？

在窗口关闭前到“操作日志”点击“导出本次日志”，保存后到[Issues](https://github.com/BerryFuwawa/dlssg-install-manager/issues)反馈。附上工具版本、系统、显卡、游戏、复现步骤和错误全文，先遮盖私人路径、用户名等信息。不要发送密码、令牌或整个备份文件夹。

## 为什么旧脚本会 GitHub 404？

旧流程强制请求 `docs/NATIVE_INI.md`，而上游布局已变化，该路径不再存在。本工具不请求这个文件，而是下载同一提交的 `README.md`、根目录 `dlssg_sm86.ini` 和 `version.dll`。以后若上游再次调整布局，会显示实际失败 URL，不会把网页当 DLL 复制到游戏。

## 任务管理器负载很高，为什么还是无法自动检测？

Windows 计数器、驱动、进程权限、不同采样窗口和后台降帧都可能影响结果。任务管理器能看到百分比，不代表本工具能读取受保护进程的 EXE 路径。

当前实现使用原生 PDH 批量获取计数器，每个进程取最忙引擎。不会把多个无关引擎相加，也不会把 LockApp/0% 当游戏。进入实际游戏画面重试；仍失败就手动选择渲染 EXE。工具不会自动修改系统计数器或关闭安全软件。

## “10 秒”是否精确到没有误差？

不是硬实时保证。后台按单调时钟的一秒绝对截止点调度，显示每个真实样本后的实际经过时间。驱动卡顿或系统调度可能延迟；初始化与路径解析在窗口之外。实测三轮采样窗口约 10.01 秒。之前逐个查询每个计数器的方式会累计到 15–16 秒，已改成批量查询。

## 手动选择后，为什么还不能安装？

还需要完全退出游戏并点击“检查游戏已退出”。选择目标和退出确认是两个明确步骤。不要重新点 GPU 检测；核对同一页面下方目标后继续即可。

## 能装到守望先锋、其他反作弊或在线游戏吗？

本工具不能确认允许与否，更不能承诺不会封禁。选择文件成功不等于游戏许可，复制成功也不等于兼容。无法确认时不要安装；不要使用本工具绕过反作弊。测试没有对真实线上游戏执行部署。

## 缓存命中了，为什么还需要网络？

只做一次轻量提交检查，以判断上游有没有更新，不会重新下载 DLL。网络不可用而缓存有效时，显示离线警告并复用；缓存无效则停止。GitHub API 限流也按网络更新失败处理。

## 不同游戏会共享备份吗？

存放位置集中，但每次安装都有独立目录。清单记录 EXE、部署目录、时间、文件原哈希和安装哈希、上游版本及提交。恢复最终确认会展示目标目录，不按相同 EXE 名称猜测目标。

## 为什么修改过的文件不能自动删除？

它可能已属于其他模组。对于安装前不存在、安装后被改过的同名文件，恢复会停止，而不是误删。先保留当前文件，阅读恢复说明再手动处理。

## GUI 更新红灯是什么？为什么 DLL 已更新它还亮？

红灯仅表示 **GUI 管理器有新版**，不表示 DLL 版本。点击红灯确认后更新 GUI。DLL 每次安装独立检查上游提交。

## GUI 更新失败或系统提示不受信任怎么办？

当前 EXE 未签名，某些系统可能提示信誉未知。请核对 Releases 来源、SHA256 和源码；也可以自行构建，不要关闭安全功能或绕过安全警告。目录不可写时将程序放在个人可写目录。工具更新不会要求 GitHub 登录、密码或令牌。

## 卸载管理器后怎么保留备份？

GUI 是便携程序，删除 EXE 不会移除集中备份。需要先撤销游戏修改时，在删除 GUI 前执行恢复。不要把删除“文档”下工具目录当成卸载游戏 DLL 的方法。
