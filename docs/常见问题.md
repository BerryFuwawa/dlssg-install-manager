# 常见问题

从下载到首次安装的完整步骤见[新手教程](新手教程.md)。

## 支持 RTX 40 系吗？

v2.1.0 适配上游 0.4.x 的 RTX 40 PTX 路线，标为“实验性支持”，包括 Laptop、Ti、SUPER 型号。需要上游要求的 NVIDIA R580+ 驱动；没有本项目实卡验证，不承诺性能或倍率。

## v2.0.0 提示 DLL 大小异常？

上游代理已缩小，运行库和内核分离到 dlssg_sm86/。请使用适配完整包的 v2.1.0；不能只放宽旧版大小检查后继续复制两个文件，否则会漏装必需载荷。

## 为什么首次升级仍要重新下载？

旧缓存只有两个部署文件，不是完整包。需要联网重建一次，以后提交未变就复用。失败保留旧缓存与游戏原文件。

## GitHub 下载哪个附件？

推荐 portable.zip，解压后打开里面的 EXE。Source code 是源码，update-manifest.json 是自动更新校验文件。开发版未正式发布时，Releases 不会自动提供开发版下载。

## 自动检测失败，任务管理器负载却很高？

进程权限、计数器、采样窗口或后台降帧都可能影响结果。进入实际场景重试，仍失败就手动选择真正的游戏 EXE，不选启动器、播放器或卸载器。

## 选好程序后按钮仍灰色？

正常退出游戏，点击“检查游戏已退出”。不需要重新自动检测。有残留进程或同名进程路径无法确认时，工具会要求重新检查。

## 检查缓存会更新所有游戏吗？

不会，只准备共享文件。更新某个游戏仍需选择其 EXE、退出检查、备份并安装。

## 更新会保留自定义 INI 吗？

不自动合并。原文件先备份，部署官方默认 INI。自定义参数请额外保存并核对新文档。只改日志等级则仅变更 INI 的 Logging.Level。

## 为什么提示 winmm.dll 或 dxgi.dll？

这些名称可能属于旧上游，也可能属于其他模组。工具只列出、不删除。确认来源后再操作，不要删除不认识的 DLL；上游自身的代理同一时间只应使用一个。

## 恢复会删除日志吗？

不会。logs/ 不参加载荷替换或恢复。未列入恢复点的新文件也不删除；安装新增文件若被其他工具改过，恢复会提示，而非直接删掉。

## 删除 EXE 就算卸载？

不是。想撤销游戏修改，应先在“备份与恢复”中选择正确记录。保留备份，不要用清空文档目录代替恢复。

## 安装后没有开关或游戏打不开？

退出游戏、保留日志，必要时恢复。核对渲染 EXE、D3D12、驱动和游戏帧生成支持，不要反复覆盖或乱改代理名。兼容边界见[已知限制](使用说明.md#已知限制)。

## 权限错误、文件占用或不受信任提示？

关闭游戏和占用文件的程序，将管理器放在个人可写目录。核对来源后再决定是否需要管理员运行；不要改系统目录权限、关闭安全软件或绕过组织策略。

## 高缩放找不到按钮？

最大化窗口并滚动内容区，不必把 Windows 缩放改成 100%。不建议额外强制高 DPI 缩放替代。反馈时附分辨率、缩放比例和截图。

## 怎么反馈？

关闭窗口前从“操作日志”导出本次记录。到[Issues](https://github.com/BerryFuwawa/dlssg-install-manager/issues)提供版本、系统、显卡、游戏、步骤和完整报错。遮盖私人路径、用户名，不发密码、令牌或整个备份。
