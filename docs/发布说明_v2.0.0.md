# v2.0.0 · 首个 GUI 正式版

把原来的批处理操作变成中文图形界面：选择游戏 → 检查退出 → 备份并安装，手动选择后也能直接继续。

## 第一次下载，选这个

在本页 **Assets** 下载 `DLSSG-Install-Manager-v2.0.0-portable.zip`，右键“全部解压缩”，打开里面的 `DLSSG-Install-Manager.exe`。包内附有中文教程和截图，不用安装 Python 或 .NET SDK。`Source code` 是源码，普通使用者不用下载。

## 本版功能

- Windows 11 风格圆角界面，按下、悬停和键盘焦点反馈；兼容设计面向 Windows 10/11 x64。
- DPI 自适应，100%–300% 布局回归通过，小屏幕可滚动访问操作区。
- 约十秒真实 GPU 采样，识别实际渲染进程；支持手动选择 EXE。
- 安装前确认游戏退出，多次复查；先备份，再替换，失败时尝试回滚。
- Windows“文档”中集中缓存和备份，跨游戏复用；每次安装自动检查上游提交。
- GUI 启动时默认检查新版本；有新版时右下角红灯，点击确认后更新并重启。
- 修复旧脚本请求已移除配置文档导致的 GitHub 404。

## 使用前请注意

- 需要 Windows 10/11 **64 位**和 .NET Framework 4.7.2+。Win10 尚未在独立设备实测；已公开测试范围和局限。
- 非 NVIDIA 官方工具。只用于允许修改的游戏，不绕过反作弊，不能承诺在线游戏账号安全或兼容性。
- 安装成功只代表文件部署成功，帧生成仍需游戏本身支持，并在游戏内设置；不要把它当成给所有游戏增加帧生成的万能工具。
- 本版管理 `version.dll` 和配套 `dlssg_sm86.ini`，不自动安装其他名称的代理 DLL；安装/更新会备份后写入默认 INI，不自动合并自定义参数。
- EXE 未做数字签名；请核对仓库来源，不要关闭系统安全功能。程序不会向你索要 GitHub 密码或令牌。
- 不附带上游 DLL，首次安装需联网下载；公共缓存存在且校验通过时可离线复用。

63 项核心/更新检查 + 60 项界面/DPI 检查通过，共 123 项；没有向真实游戏部署。详细范围见[测试记录](https://github.com/BerryFuwawa/dlssg-install-manager/blob/main/docs/测试记录.md)。

## 附件用途

- `DLSSG-Install-Manager-v2.0.0-portable.zip`：推荐下载，包含程序、中文教程与截图。
- `DLSSG-Install-Manager.exe`：只需要程序时下载，可单独运行。
- `update-manifest.json`：自动更新校验信息，不用手动修改。
