# v2.1.0 · 完整包与 RTX 40 实验性支持

状态：待正式发布。

## 本版功能

- 适配上游 0.4.x 完整包，获取同一提交的代理、INI、后端、帧生成内核包和运行库。
- RTX 40，包括 Laptop、Ti、SUPER，显示实验性支持；提示 NVIDIA R580+ 驱动要求。
- 缓存记录完整文件列表，下载显示文件数和字节进度。旧两文件缓存需联网重建一次，失败保留原内容。
- 逐文件备份覆盖新增、替换和移除，安装失败回滚；恢复保留日志和未列入恢复点的文件。
- 兼容 v2.0.0 和旧批处理备份；修改日志等级仅备份 INI。
- 保留 Windows 10/11 圆角 GUI、DPI 自适应和右下角更新红灯。v2.0.0 客户端可识别并校验 v2.1.0。

## 新手怎么用

下载便携 ZIP，右键“全部解压缩”，打开其中的 EXE。选择游戏 → 正常退出 → 检查退出 → 备份并安装，完成后到游戏内验证帧生成。

便携包附中文[新手教程](新手教程.md)、[常见问题](常见问题.md)和[六张截图](界面截图.md)，不需要命令行、Python 或 .NET SDK。

## 验证

93 项核心/更新检查、60 项 UI/DPI 检查通过。真实上游包完成隔离目录部署与恢复；原版 v2.0.0 客户端的更新检测和新 EXE 校验通过。[详细记录](测试记录.md)

## 已知限制

RTX 40 为实验性支持，未进行本项目实卡验证，不承诺性能或倍率。仅用于允许修改的游戏；安装完成不等于帧生成已启用。EXE 未签名。更多边界见[使用说明](使用说明.md#已知限制)。
